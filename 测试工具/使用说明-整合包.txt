【这是什么】
  一款纯本机运行的 AI 视觉小说（galgame）生成器：大语言模型实时写剧情，
  生图 API 或本地 SD WebUI 画立绘与背景，支持 TSF（性别转换）与普通
  Galgame 双模式。所有角色均为成年人。
  程序不需要安装 Python，也不需要联网安装依赖，解压即用。

【系统要求】
  · Windows 10 / 11（64 位）
  · 首次启动需要 10-30 秒（单文件程序要自解压，属正常现象）
  · 需要自备大模型 API Key 才能生成剧情；不填 Key 会进入演示模式，
    可用内置剧情与占位立绘完整体验全部流程与数值机制
  · 本地绘图可选装 SD WebUI（默认连 127.0.0.1:7860），不装也行

【三步开始】
  1. 把压缩包解压到一个固定目录（例如 D:\TSF_Galgame），
     路径别含特殊符号，也别放 C:\Program Files（无写入权限）
  2. 双击 TSF_Galgame.exe
     会弹出一个黑色命令行窗口（这是游戏服务，属正常），
     随后浏览器自动打开 http://127.0.0.1:8765
     若弹出 Windows 防火墙授权，选择「允许」（手机/平板同局域网访问时需要）
  3. 进入页面后点右上角「⚙ 设置」，填入 API Key 并保存，立即生效

  · 关闭那个命令行窗口 = 停止游戏服务，存档不会丢
  · 想让同一局域网的手机玩：看命令行窗口打印的
    「局域网设备」地址（如 http://192.168.1.5:8765），手机浏览器打开即可

【配置 API】
  对话模型与绘图模型都支持 OpenAI 兼容接口，任选其一填入即可。

  对话/剧情（Chat Completions）
    智谱 AI    https://open.bigmodel.cn/api/paas/v4             glm-4-flash
    DeepSeek   https://api.deepseek.com/v1                      deepseek-chat
    月之暗面   https://api.moonshot.cn/v1                        moonshot-v1-8k
    通义千问   https://dashscope.aliyuncs.com/compatible-mode/v1  qwen-plus
    OpenAI     https://api.openai.com/v1                        gpt-4o-mini

  立绘/背景（二选一）
    ① 云端 Images Generations：同上任一家的绘图模型
    ② 本地 SD WebUI：填入 http://127.0.0.1:7860，显卡越好出图越快

  Key 只保存在你自己电脑的 config.json 里，不会上传到任何地方。

【文件与数据位置】
  TSF_Galgame.exe       主程序（单文件，内置界面与 AI 抠图引擎）
  开发者更新游戏状态.bat          安装 update\ 里的新版本
  config.json           你的配置与 API Key（首次运行自动生成）
  角色库\               导出的角色卡与立绘素材（玩了才有）
  README.md             完整功能说明与进阶配置

  对局进度、立绘缓存、CG、剧本存放在**独立的数据目录**：
    D:\TSF_Galgame_Data\data\         （存在 D 盘时）
       或 %LOCALAPPDATA%\TSF_Galgame\data\
  这个目录与程序分开，所以换目录、更新版本都不会丢档。
  备份游戏进度 = 备份这个目录。

【如何更新版本】
  1. 把新版本的 TSF_Galgame.exe 放进 update\ 文件夹
     （没有这个文件夹就手动新建一个）
  2. 双击 开发者更新游戏状态.bat，脚本会自动关闭旧进程、替换程序、启动新版本
  存档与配置都在数据目录里，不会受影响。

【常见问题】
  · 双击后没反应 / 窗口一闪而过
      多半是杀毒软件拦截了单文件程序。把它加白名单后重试；
      也可以右键 exe →「以管理员身份运行」试一次。
  · 浏览器没自动打开
      手动访问 http://127.0.0.1:8765 即可；还不行就按 Ctrl+F5 强制刷新。
  · 提示端口 8765 被占用
      说明已经有一个实例在跑，关掉旧的命令行窗口再启动。
  · 立绘生成很久
      云端绘图接口单张通常 10-30 秒，本地 SD 取决于显卡；
      生成中显示「立绘生成中」横幅是正常等待，不是卡死。
  · 页面显示不正常 / 改了设置没生效
      按 Ctrl+F5 强制刷新；界面已禁用缓存，一般无需清理。
  · 想搬去另一台电脑
      整个程序目录 + 数据目录（D:\TSF_Galgame_Data）都拷过去即可。
