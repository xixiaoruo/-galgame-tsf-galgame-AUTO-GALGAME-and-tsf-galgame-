# 自动化AI Galgame · 即时物语生成器

> 此ai是作者为了满足自我对目前市面上没有galgame形式的酒馆与逐渐变化的自动化 tsf类型的游戏所制作，这个项目目前代码比较薄弱，希望各个大佬能够指点修改。
>
>(以下自我介绍大部分是由ai生成)

接入**大语言模型 API** 与**绘画 API**（均为 OpenAI 兼容接口）的**互动视觉小说生成器**，
纯本机运行，内置四种玩法模式——**不止 TSF**。

## 四种模式

开新局时选择，游戏内也可随时用右上角按钮切换。

### ♥ 普通 Galgame 模式

日式视觉小说的标准玩法：与角色相处、把关系推进下去，剧情围绕日常、情感与情感桥段展开。

| 数值 | 起始 | 含义 |
|---|---|---|
| 心情 ♪ | 45 | 当前愉悦度，高 = 轻松满足，低 = 低落压抑 |
| 好感 ❣ | 20 | 角色对你的好感，随互动起伏 |
| 敏感度 ❀ | 0 | 情绪与敏感度，高 = 轻易动情 |
| 情绪峰值 ◉ | 0 | 情绪峰值的累积与回落 |

- **命令面板**：更衣（便服／贴身衣物／特殊着装／换回默认）与亲密互动类动作，每个动作对上述
  四项数值有不同影响（如「亲密接触」好感 +2、敏感度 +4；「拥抱」好感 +2、敏感度 +3）
- **剧情由 LLM 实时续写**：每轮给出剧情段落 + 分支选项，选项会标注将要影响的数值倾向
- **内容分级**：全年龄（默认）／16+／进阶；进阶 档另可选内容强度（温和／成熟／浓烈）
  与「支配向」开关。贴身衣物／特殊着装更衣与支配类命令**仅在 进阶 下可用**

### ♀ TSF Galgame 模式

在普通模式之上叠加一条**性别转变**主线：

- **性别同化率 0~100%** 驱动**六个阶段**（默认；四段/十段可在设置中切换）：
  初变（0-20%）→ 微塑（20-40%）→ 迷离（40-60%）→ 绽放（60-80%）
  → 羽化（80-99%）→ 新生（100%）
- 阶段跃迁时自动生成新立绘并播放全屏跃迁演出；主角「外貌锚点」在各阶段间保持一致
- **六段演变工坊**（1.8 新）：在游戏里点「🧬 六段」或 Ctrl+K 搜索，用同一条引擎
  逐段生成完整转变过程，可单段重画/查看/取消，已生成段自动复用
- 另有一套专属数值：体质特征／感官适应度／身份认同／习惯同化度／沉浸度
- 剧情聚焦「成年男性 → 中性 → 成年女性」过程中身体变化的陌生感、心理认同与人际关系

### 🕯 CoC 跑团模式

在普通 Galgame 与 TSF 之外，新增一套**克苏鲁式调查跑团**玩法；不依赖立绘管线，
以文字、数值与掷骰推进：

- **DOOM 末日倒计时**：调查、休息、进商店、重掷货架都会改变 DOOM；100% 触发古神结局
- **双资源**：体力 STA / 意志 REA 归零都会结束对局，并各有独立结局
- **SAN 理智值**：独立 0–99，d100 理智检定、失败损失、单次损失 ≥5 触发临时疯狂；
  SAN 归零进入 `END_SAN_ZERO`；镇静剂、嗅盐、威士忌、调查笔记可回复
- **d12 调查检定**：STR / DEX / PER / KNW / CHA 对 SAFE / LOW / DANGEROUS / DOOMED
- **物品栏与装备**：背包 / 仓库 / R-C-B 装备槽；绷带、医疗包、护符、武器与仪式用品
- **固定商店场景**：盐川杂货铺、二十四小时药房、旧书与骨董；固定店主与场景文本，
  种子库存、购买/出售/重掷，进店与重掷按规则增加 DOOM
- **自动生成物品**：搜刮成功才生成物品；商店货架按本局种子自动抽取
- **CoC 剧本预设**：盐川町原版 + 黄昏洋馆、雾港、极地观测站、夜班学园、雨夜失踪案；
  每个预设带独立地点/谜团/事件卡与初始物品，也可粘贴自定义 JSON 剧本
- **AI 控制台**：查看模型请求、reasoning_content（若支持）、原始输出、token/耗时；
  直接修改当前对话，或填写持续生效的「导演指令」控制下一轮写法

### 🕯♀ CoC×TSF 模式

同一套 CoC 规则 + TSF 转变进度与立绘：

- CoC 的 DOOM / STA / REA / SAN、物品、商店、剧本全部可用
- 额外叠加性别同化率与 TSF 阶段立绘；转变会影响属性检定、衣物/装备可用性
- 适合想在调查跑团中同时推进身体与身份变化的玩法

### 四种模式共用同一套引擎

立绘生成与自动抠图、NPC 表情差分、场景背景、CG 关键桥段插画、换装与服装状态跟踪、
世界观／角色／故事书／AI 故事大纲、12 条预置创作指令、自动存档与恢复、立绘导出
——TSF / 普通 / CoC×TSF 均可使用；纯 CoC 模式以文字与状态面板为主，不生成立绘。
详见下方功能总览。

> 内容边界：所有角色均为成年人。叙事尺度由界面上的**内容分级政策**调控，
> 政策未允许的尺度一律不写。

## 功能总览

- **TSF 数值系统**（右上角状态框，可随时收起/调出；普通模式的四项数值见上方「四种模式」）：
  - 性别同化率 0~100%（驱动四个阶段的立绘更换）
  - 体质特征 / 感官适应度 / 身份认同 / 习惯同化度 / 沉浸度
  - 每轮剧情后数值实时更新，变化量以 ▲▼ 标注、进度条动画
- **六阶段转变立绘**（默认；四/十段可配）：初变 → 微塑 → 迷离 → 绽放 → 羽化 → 新生。
  阶段跃迁时自动生成新立绘，并播放全屏跃迁演出；主角「外貌锚点」在各阶段间保持一致
- **六段演变工坊**：用游戏内同一条立绘引擎按当前锚点逐段生成六段全程，
  卡片显示每段状态/代表同化率，可单段生成、强制重画、取消与看大图
- **绘画线路优化**：成品缓存（同提示词/参数/种子直接复用）、节能模式
  （重试减半/关 Hires/跳过打标）、性能与消耗面板（本局耗时/缓存命中/串行队列）
- **随机制服**（1.9）：31 套内置制服提示词（学园/神社/女仆/医疗/职场/军装/
  奇幻/和风/偶像/居家/科幻），开局按世界观抽取，游戏内换装按当前场景抽取；
  也可从预设下拉直接选
- **角色卡 2.0**（1.9）：身份 / 外貌 / 性格 / 背景四栏；`✨ 背景` 用 AI 自动
  谱写来历与剧情钩子，`🎲` 本地随机一位角色，`📚` 从角色库单卡回填；
  角色卡重名/与主角同名会被拦截
- **感情机制**（1.9）：好感映射「陌生→认识→熟悉→亲近→心动→依恋→恋人」，
  每幕记录情感记忆并注入 AI 提示词；长期不出场的角色会自然冷却，关系升级
  时右下角会提示
- **旧档案找回**（1.9）：设置 →「🧰 旧档案找回」扫描 `档案备份` / 旧数据 /
  回收站 / 角色库 / zip，补齐 1.9 字段后放回；同名同内容只补字段，不同内容
  另存副本，绝不覆盖
- **显示稳定性**（1.9.1/1.9.3）：弹窗/命令面板/加载层去掉全屏 `backdrop-filter`，
  打开窗口不再连带背景闪一下；选项按钮禁用文本选择并在拖动时抑制 hover 尾迹，
  不会再出现「拖过去整排全亮、点不动」；选项 hover 改为 JS 单点高亮，Qt 下不会粘住上一项
- **设置与存档修复**（1.9.4/1.9.5/1.9.6）：点「API 设置」立即弹窗、配置异步填充
  （SD/Comfy 探测 0.8s 超时 + 10s 缓存，读取中禁用保存）；读档后下一幕不再写回
  旧 sid，存档列表禁用 HTTP 缓存并即时刷新；同秒连存不再互相覆盖；设置里的原生
  下拉选中后主动失焦，不再残留上一项高亮/残影
- **旧存档修复**（1.9.7～1.9.12）：读档时把上次中断的 `pending` 资产恢复或转为
  可重试、清空场景补生成预算、清空旧场景提示词缓存；背景失败后真正重新入队；
  背景/CG 不再被「多人同框」或绿色场景误杀；CG 生成完成后由资产轮询自动补图，
  不再只在进入该幕时加载一次
- **开局流程**：世界观 + 主角外貌选项（发色/瞳色/服装/气质，实时组装外貌锚点）
  + 其他角色 + 故事书 + **AI 生成故事大纲**（自动注入后续所有剧情提示词）
  + **AI 指令注入**（文风/限度/节奏等 12 条预置指令多选 + 自定义）
- **指令注入**：开始界面「⑥ AI 指令注入」与游戏内「⚡ 指令」窗口共用同一套
  预置指令（节奏 / 文风 / 描写 / 氛围 / 限度 / 互动 六组，可多选），开局选择后
  随时可在游戏内调整，下一幕生效；预置文案以服务端为准防篡改
- **立绘画面保障（内置，无需配置）**：立绘提示词强制「必须全身像（从头到脚完整）、
  必须纯白背景无阴影、单一角色、合理取景距离、完整居中不出框」，SD WebUI 模式
  另有立绘专用负面词（禁止裁切/出框/背景/渐变背景）；背景提示词强制「纯场景、
  禁止出现人物」——从源头区分角色与背景；生成后自动抠图
- **galgame 框内合理呈现**：全身立绘抠图后按目标比例 1.35 自适应裁成经典
  「膝上构图」；半身/大头比例保持原样
- **按身高比例统一显示大小**：立绘显示高度按裁剪后图片的高宽比（近似角色
  身形）归一化——高挑角色显示更高、娇小角色更矮，整体在基准高度 ±15% 内，
  同屏视觉一致
- **修图软件适配导出**：状态面板「📤 导出立绘」把本局立绘整理为
  `data/exports/<标题>_<会号>/<角色名>/` 目录：透明底 PNG（角色名_变体.png
  干净命名）+ 白底平铺 JPG + manifest.json 清单（尺寸/变体/角色），导出后
  自动打开文件夹
- **内置自动抠图 v3.3**（通用立绘抠图）：降采样多种子泛洪 + 自适应容差 +
  **二次泛洪**（装饰边框污染背景色估计时，用边框内侧颜色重新估计再泛洪）+
  **贴边边框扫描剥离**（金色雕花相框等，宽度自适应）+ 只保留主体连通块
  （水印/噪点碎片）+ 接触阴影侵蚀 + 边缘带 alpha 重估与去白边（defringe）。
  1024×1760 大图处理约 1~2 秒。示例图：`static/samples/`
- **故事书（Lorebook）**：世界规则/伏笔/人物秘密条目——「常驻」每轮注入，
  带关键词的条目在剧情命中关键词时才注入（省 token）
- **选项数值倾向**：AI 生成的选项会标注倾向影响的数值（⟪认同⟫⟪沉溺⟫等）
- **立绘体验**：生成中显示「🎨 立绘生成中，请稍等…」横幅与占位剪影，就绪后淡入；
  状态框内一键「📁 打开立绘文件夹」直达资源管理器
- 其他：NPC 表情差分立绘、场景背景图、打字机对话框、剧情历史、自动存档与恢复

## 配置 API

页面「⚙ 设置」中填写并保存（立即生效），或编辑 `config.json`。Key 只保存在本机。

### 对话/剧情 API（OpenAI 兼容 Chat Completions）

| 服务商 | Base URL | 模型示例 |
|---|---|---|
| 智谱 AI | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` / `glm-4-air` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |

| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |

### 立绘/背景 API（两种服务类型）

**① OpenAI 兼容 Images Generations（云端）**

| 服务商 | Base URL | 模型示例 |
|---|---|---|
| 智谱 AI | `https://open.bigmodel.cn/api/paas/v4` | `cogview-3-flash` / `cogview-3` |
| OpenAI | `https://api.openai.com/v1` | `dall-e-3` |

**② SD WebUI 本地整合包（免费无 Key）**：在「⚙ 设置 → 立绘/背景生成」中把
**服务类型切换为 SD WebUI**，Base URL 填整合包地址（通常是
`http://127.0.0.1:7860`），API Key 留空即可。要求整合包以 `--api` 参数启动
（A1111 / Forge 系默认开启）。可调参数（config.json 的 image 段）：
`sd_portrait_size`（默认 1024x1760，注意 SD1.5 模型远超 512 训练分辨率可能出重复肢体，如遇异常可改回 512x768 或 512x880）、`sd_background_size`（768x512）、
`sd_steps`（25）、`sd_cfg`（7）、`sd_sampler`（DPM++ 2M）、`negative_prompt`。

> 安全设计：OpenAI 模式拒绝本地/内网地址；SD WebUI 模式仅用于你本机的整合包。
> 混合模式可用：例如「剧情=云端 LLM + 立绘=本地 SD WebUI」。
> 注意 SD1.5 系模型对中文提示词理解有限，若立绘效果不理想，可将 `game.style_suffix`
> 改写为英文关键词（如 "anime visual novel style, half body, white background"）。

## 玩法说明

1. **开始界面**五步：① 世界观（可 🎲 随机生成）→ ② 主角设定（下拉选择外貌，
   自动组装「外貌锚点」）→ ③ 其他角色（0~4 个，可为空）→ ④ 故事书条目 →
   ⑤ 大纲（🤖 生成或手写，可跳过）。
2. **游戏界面**：点击对话框推进（再点跳过打字机），选项带数值倾向标记；
   选择后 AI 续写下一幕并返回 `stats_delta`，状态框实时刷新。
3. **数值与阶段**：AI 按剧情合理性给出每项 0~±6（重大转折 ±12）的变化；
   性别同化率跨过 20/50/80 阈值时触发阶段跃迁演出与新立绘生成。

## 工作原理

- 每轮 LLM 返回严格 JSON：场景、对话数组、选项（含 bias）、`stats_delta`、`identity`；
  后端清洗数值（幅度限制 ±15、截断 0~100）、派生阶段。
- 主角立绘 prompt = 阶段形体描述 + 外貌锚点 + 统一风格后缀（纯白背景），
  Pillow 白底转透明后按内容哈希缓存；同锚点同阶段跨局复用。
- 大纲与故事书（常驻 + 关键词命中）注入每轮 system prompt；
  历史超过 `history_rounds` 轮自动摘要压缩。
- 会话自动存档到 `data/saves/`，刷新或重启自动恢复。

## 命令 / 换装 / CG 回廊（游戏内顶栏）

- **⚡ 命令面板**：选择目标角色后下达命令——更衣（便服 / 贴身衣物 / 特殊着装 / 换回默认）
  与强制行为（亲密接触 / 亲密拥抱 / 过激互动 / 亲密互动）。更衣立即生效（立绘按新服装重新生成，
  剧情描写同步）；命令场面自动收藏为 CG，并带数值变化（如过激互动 → 身体特征/沉溺/习惯上涨）。
- **👗 换装**：随时给主角或 NPC 换装（预置：默认 / 便服 / 贴身衣物 / 特殊着装，也可自定义如「晚礼服」）。

### 内容分级与进阶内容（进阶）

- 开局与设置中均有「内容分级（全年龄 / 16+ / 进阶）→ 开启 进阶内容 → 内容强度
